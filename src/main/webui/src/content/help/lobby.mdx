# Lobby & Joining Games

<p className="help-lede">Where you create games, join public games, and register a deck to play in one.</p>

The Lobby has three parts: private game management, browsing/joining public games, and registering a deck against any game you've joined. Creating a game yourself is optional — the site automatically generates a few public games that are free to join at any time.

There are two steps to actually playing:

1. Be invited to a private game, or join a public one.
2. Register a deck against that game.

Games are created from the **Create Game** section of the Lobby. A game's name must be unique across every game on the site, and can't contain special characters. Tick **Public Game** to let anyone join it.

## Private Games

If you create a private game, you're responsible for inviting other players and choosing when to start it. The only requirement to start is at least one registered player — so a private game is also a convenient way to test a deck, or try out commands, without waiting on real opponents.

## Public Games

Public games are created automatically every few minutes, or manually by any player who ticks **Public Game**.

- They expire 5 days after creation — registering a deck to one refreshes its expiry, which keeps game slots in active use.
- A public game starts automatically once it reaches 5 registered players.
- If a public game is about to expire with exactly 4 registered players, it starts as a 4-player game instead. There's currently no way to force-start a public game with 3 or fewer players — use a private game for that.

You can leave a public game any time before it starts.

## Registering a Deck

Deck registration — for both private and public games — happens in the **Register Deck** section. Every deck you have saved in the modern format is available to pick from; choose the deck and the game, then register. You can change your registration at any time before the game actually starts.

<Callout title="Tip">
  Only decks saved in the modern format (see [Deck Editor](/jol/help/deck-editor)) can be registered — a **LEGACY** deck needs to be opened and re-saved first.
</Callout>
