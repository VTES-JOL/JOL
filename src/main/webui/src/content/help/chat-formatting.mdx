# Chat & Text Formatting

<p className="help-lede">Every chat box on the site supports a few macros for quick formatting.</p>

- **Card and discipline links** — wrap a name in square brackets and it becomes a link with a hover preview: typing `[Parity Shift]` renders as <CardLink id="101353">Parity Shift</CardLink>, and a discipline short code like `[OBF]` renders as its icon: <span className="icon OBF" />.
- **Emoji** — wrap a short name in colons to get its emoji: `:shrug:` → 🤷, `:joy:` → 😂, `:rofl:` → 🤣, and so on.
- **Direct action** — `(D)` renders as the direct-action icon: <span className="icon D" />.

<Callout title="Tip">
  These work in every chat box on the site — the main lobby chat, a game's chat, and tournament chat all share the same formatting.
</Callout>
